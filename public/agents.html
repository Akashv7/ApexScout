The agents behind the numbers.

Four rule-based agents currently run for real against the live dataset. They're deliberately simple and fully inspectable (see /lib/agents in the source) rather than opaque ML calls — a documented, debuggable baseline that a real classifier or video model can slot into later without changing how the rest of the app talks to them.

TI
Talent Index Engine
ACTIVE · RUNS ON EVERY MATCH

Elo-style team ratings + opponent-weighted player impact scoring. This is the core differentiator — see lib/ratingEngine.js. Recomputes fully whenever a match is recorded.

DA
Discovery Agent
ACTIVE

Flags players whose Talent Index is high relative to their league's strength — the exact "hidden gem" case the platform exists for. Powers the homepage feed.

VA
Verification Agent
ACTIVE · ON-DEMAND

Checks logged stats against format-specific plausibility limits (e.g. max wickets/strike rate for the format), and can upgrade a player's trust tier automatically when their record checks out. Try it from any player's profile page.

SM
Scout-Matching Agent
ACTIVE

Ranks players against a scout's search criteria and generates a plain-language reason for each recommendation — powers Scout Zone's results list.

MO
Moderation Agent
ACTIVE · RUNS ON REGISTRATION

Screens every self-submitted bio for spam/contact-harvesting patterns and basic profanity before it's saved — see it reject text live in the box below (nothing is actually submitted).

NOT YET BUILT — HONEST ROADMAP

These four agents are real but rule-based. Two agents from the original design are still just concepts, not code: Video Highlight Extraction Agent (would need a computer-vision pipeline to auto-detect key moments in uploaded footage) and a genuinely learned, ML-based upgrade to Verification (currently rule-based plausibility checks only, no video cross-referencing). Both are the natural next build phase.
